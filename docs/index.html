Loading libraries & Reading in data

This should be done at the top of your quarto doc, typically after the yaml, and all wrapped in a R code chunk. All the loaded data will then be available throughout the rest of your document.

Code 
```{r}
#| label: setup
#| message: false
#| warning: false

# Loading all your libraries
library(tidyverse)
library(knitr)

# Reading in data
# Example: my_data <- read_csv("path/to/data.csv")
# For this cheat sheet, we will use the built-in mtcars dataset
my_data <- mtcars
```

Code chunks with options

Code 
# Common chunk options:
# echo: true/false -> Show or hide the code in the output.
# eval: true/false -> Run or do not run the code.
# warning: false   -> Suppress warnings.
# message: false   -> Suppress messages.
# include: false   -> Run the code, but hide both code and output.

print("This code is shown (echo: true) but not executed (eval: false).")

Inserting figures and figure captions

Code 
```{r}
#| label: fig-mpg
#| fig-cap: "Scatterplot of Car Weight vs. MPG"

ggplot(my_data, aes(x = wt, y = mpg)) +
  geom_point() +
  theme_minimal() +
  labs(x = "Weight", y = "Miles Per Gallon")
```
TipTip

Notice how we labeled the figure above with the option #| label: fig-mpg

We can then reference that figure in our text, for example…

As shown in Figure 1, heavier cars typically have lower MPG.

Table outputs

Code 
```{r}
#| label: tbl-summary
#| tbl-cap: "Average MPG by Cylinder Count"

my_data |> 
  group_by(cyl) |> 
  summarise(avg_mpg = mean(mpg)) |> 
  kable() # kable() makes a clean markdown table
```
TipTip

This time we labeled the table above with the option #| label: tbl-summary

We can then reference that table in our text.

Please refer to Table 1 for the exact averages.

Formulas with LaTeX

Insert inline math equations using a single dollar sign: $y = mx + b$.

For centered display equations, use double dollar signs:

$$E = mc^2$$

Insert inline math equations using a single dollar sign: \(y = mx + b\).

For centered display equations, use double dollar signs:

\[E = mc^2\]

Citations

Adding references to quarto document

  1. Open your .qmd file in RStudio’s Visual Editor mode, go to the top menu, and click Insert > Citation…. You can search databases (like DOI, Crossref, DataCite, or PubMed). RStudio will automatically create a references.bib file for you

  2. Open the YAML metadata block at the very top of your Quarto document and add the bibliography field pointing to your .bib file

---
title: "My Research Document"
author: "Your Name"
format: html
bibliography: references.bib
---
  1. Insert Citations in the Text
- Standard citation: This is a great paper [@heidmann2024].
- In-text citation: @ault2024 has some cool things too.
- Multiple citations: Several authors agree [@heidmann2024; @grove2024].
  • Standard citation: This is a great paper (Heidmann et al. 2024).
  • In-text citation: Ault et al. (2024) has some cool things too.
  • Multiple citations: Several authors agree (Heidmann et al. 2024; Grove et al. 2024).
